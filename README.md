## ⭐ Projetos em Destaque

### 🏢 Integração com ERP Corporativo

Desenvolvimento de integrações entre o **ERP Logix**, sistemas internos, marketplaces e plataformas logísticas.

**Tecnologias**

`C#` `ASP.NET Core` `SQL Server` `Informix` `Docker` `APIs REST`

---

### 🛒 Plataforma VTEX B2B

Desenvolvimento de APIs, automações e integrações para o ecossistema VTEX.

**Principais funcionalidades**

* Fluxos de cadastro de clientes
* Automação da análise de crédito
* Exportação do carrinho de compras
* Integrações com marketplaces
* Integração com o CRM Kommo
* Integração com sistemas internos e ERP

---

### 📱 Aplicativo Mobile para Força de Vendas

Aplicação mobile corporativa utilizada por representantes comerciais para gerenciar clientes, produtos, cotações e pedidos.

**Tecnologias**
